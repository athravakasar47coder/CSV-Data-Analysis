# CSV Data Analysis & Visualization

## Project Overview

This project performs data analysis and visualization on student
performance data stored in a CSV file.

The project uses Pandas for data analysis and Matplotlib and Seaborn
for data visualization.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Project Features

- Load student data from CSV
- Calculate average study hours
- Calculate average attendance
- Calculate average marks
- Find the student with highest Maths marks
- Generate a bar chart
- Generate a scatter plot
- Generate a correlation heatmap
- Display data insights
